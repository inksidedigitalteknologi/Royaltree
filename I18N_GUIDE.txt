CARA PAKAI DI UI
----------------

1. Composable dengan parameter currentLanguage:

   Text(LanguageManager.translate("key_name", currentLanguage, "Fallback"))

2. Composable tanpa parameter (global state):

   Text(LanguageManager.translate("key_name", AppThemePreferences.currentLanguage, "Fallback"))

3. ViewModel:

   _snackbarMessage.value = LanguageManager.translate("key_name", _currentLanguage.value, "Fallback")

CARA TAMBAH KEY BARU
--------------------

STEP 1: Buka file LanguageManager.kt

STEP 2: Cari bagian: private val translations = mapOf(

STEP 3: Tambah entry baru DI DALAM mapOf, contoh:

    "new_key_name" to mapOf(
        AppLanguage.INDONESIAN to "Text Indonesia",
        AppLanguage.ENGLISH to "English Text",
        AppLanguage.SPANISH to "Texto Espanol",
        AppLanguage.CHINESE to "Chinese Text",
        AppLanguage.ARABIC to "Arabic Text",
        AppLanguage.JAPANESE to "Japanese Text"
    ),

STEP 4: Pakai di UI:

    Text(LanguageManager.translate("new_key_name", currentLanguage, "Fallback"))

BEST PRACTICE
-------------

  1. JANGAN hardcode text user-facing - selalu pakai LanguageManager
  2. Fallback WAJIB - kasih text Indonesia sebagai default
  3. Reuse key - pakai common_* untuk aksi umum (Batal, Kirim, OK)
  4. Skip non-translatable:
     - Emoji
     - Angka murni
     - Nama brand (Node.js, PHP, WhatsApp)
     - API keys / URL
     - JSON field names
     - Log tags
  5. Test multi-bahasa - minimal ID + EN + ZH
  6. JANGAN pakai '// comment,' setelah argumen - bikin syntax error
