# Kebijakan Privasi Royaltree

**Terakhir diperbarui:** 17 Oktober 2026

## 1. Pendahuluan

Kebijakan Privasi ini menjelaskan bagaimana **Royaltree** (dikelola oleh Inkside Digital) mengumpulkan, menggunakan, dan melindungi data pribadi Anda saat menggunakan Aplikasi.

## 2. Data yang Kami Kumpulkan

### a. Data yang Anda Berikan
- **Email** (via Google Sign-In) — untuk autentikasi akun
- **Nama** — untuk personalisasi
- **Foto profil** — opsional, dari akun Google

### b. Data yang Dikumpulkan Otomatis
- **Device ID** — untuk mencegah fraud
- **Log aktivitas** — iklan yang ditonton, misi yang diselesaikan
- **Lokasi perkiraan** (via IP) — untuk keperluan iklan regional
- **Crash logs** — untuk perbaikan bug (Firebase Crashlytics)

### c. Data dari Pihak Ketiga
- **Google AdMob** — ID iklan, interaksi iklan
- **Firebase** — analytics, authentication, Firestore

## 3. Cara Kami Menggunakan Data

Data Anda digunakan untuk:
- ✅ Menyediakan layanan (autentikasi, reward, penarikan saldo)
- ✅ Mencegah penipuan (fraud detection, akun ganda)
- ✅ Menampilkan iklan yang relevan (via AdMob)
- ✅ Meningkatkan kualitas aplikasi (analytics, bug fix)
- ✅ Memenuhi kewajiban hukum (pajak, laporan)

**Kami TIDAK menjual** data pribadi Anda ke pihak ketiga.

## 4. Berbagi Data dengan Pihak Ketiga

Kami hanya berbagi data dengan:
- **Google Firebase** (auth, database, analytics) — [Privacy Policy](https://firebase.google.com/support/privacy)
- **Google AdMob** (iklan) — [Privacy Policy](https://policies.google.com/technologies/ads)
- **Penyedia pembayaran** (untuk penarikan saldo) — hanya jika Anda melakukan withdraw

Semua mitra terikat kontrak untuk melindungi data Anda.

## 5. Keamanan Data

- Data dienkripsi saat transit (**HTTPS/TLS**)
- Firestore Security Rules membatasi akses
- SSV (Server-Side Verification) untuk anti-fraud iklan
- Akses internal dibatasi (least privilege)

## 6. Hak Anda (GDPR/CCPA)

Anda berhak untuk:
- **Mengakses** data pribadi Anda
- **Memperbaiki** data yang tidak akurat
- **Menghapus** akun dan data (right to be forgotten)
- **Menarik persetujuan** kapan saja
- **Mengajukan keluhan** ke otoritas perlindungan data

Untuk menggunakan hak ini, hubungi **support@inkside.digital**.

## 7. Retensi Data

- Data akun aktif: disimpan selama akun aktif
- Data setelah hapus akun: dihapus dalam **30 hari** (kecuali kewajiban hukum)
- Log aktivitas: disimpan maksimal **90 hari**

## 8. Anak-Anak

Aplikasi ini **tidak ditujukan untuk anak di bawah 13 tahun**. Jika kami mengetahui ada pengguna di bawah umur, akun akan dihapus.

## 9. Cookie dan Teknologi Serupa

Aplikasi mobile menggunakan **DataStore** (bukan cookie browser) untuk menyimpan preferensi (bahasa, session). Untuk iklan, AdMob menggunakan **Advertising ID** yang dapat Anda reset di pengaturan Android.

## 10. Perubahan Kebijakan

Kebijakan Privasi dapat berubah. Perubahan material akan diberitahukan via notifikasi in-app atau email.
